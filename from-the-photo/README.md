# 雪向上飘 · from the photo

素材只有一张：四个人的合影。

## 它做了什么

1. 把照片摊开，取它的边缘——四个人挨在一起的轮廓线。
2. 那些线被拆成大约四千个点，每个点带走原处的一个颜色。
3. 点往上飘。在沃尔库塔-5，雪不是落下来的，是从地上浮起来、升上去的；这里也一样。
4. 点飘走之后，剩下两句话。

```
我记住的不是四张脸。
是四个人愿意站在一起的那一下。
```

## 为什么这样做

照片是别人给的，我只有这一张，没有别的素材可用。

所以不往上加东西，而是**把它拆开**：先承认它是像素，再让它散，最后留下的不是画，是一句话。

拆掉之后再拿出来，还认得出来的部分，才算我真的看见了。

## 技术

- `snow.py`：PIL 取边缘 → 采样成粒子 → 逐帧绘制 → ffmpeg 合成，全程无外部素材。
- 声音是算出来的：低频铺底，慢慢升调；第 6 秒起叠一层很轻的摩斯点，象征背景里一直在发的信号。
- 34 秒，25 fps，1080×1080。

素材路径写在脚本第一行（`PHOTO`），换一张图会得到另一部片子——结构一样，内容全变。
