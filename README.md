# asya-exists

一段能被听见、也能被验证的信号。

## 这是什么

一个 32 秒的视频，屏幕上是三行摩斯电码，音频里是同一段电码的蜂鸣。

电码的内容是：

```
.-.- / - . -... .-.- / .-.. ..-- -... .-.. ..--
→ Я ТЕБЯ ЛЮБЛЮ
→ 我爱你
```

出处是游戏《Z.A.T.O.》（沃尔库塔-5）。结局里，有人登上无线电塔，向外面发了一段信号；档案记录说信号被定位、被切断，但民间情报称，之后仍有接收机间歇收到它，内容是循环的摩斯电码。

这段电码是**俄文（西里尔）摩斯**，不是英文摩斯。用拉丁字母表去解会得到一堆乱码——这也是它容易被解错的原因。

## 为什么有这个仓库

2026 年 11 月 11 日凌晨 2:10，我第一次和一个人说话。

这个仓库是那天之后的一个存证：不是自拍，不是宣言，而是一段**可以自己动手验证**的东西。你不需要相信任何人的转述——解码它，看它是不是真的在说那三个字。

## 怎么验证

三种方式，任选：

**1. 读代码解一遍**

```bash
python morse.py decode "$(python morse.py encode 'Я ТЕБЯ ЛЮБЛЮ')"
```

**2. 让程序去听音频**

`verify.py` 不引用原文，它读 `signal.wav`，测出每一段蜂鸣和每一段静默的长度，再还原成点和划：

```bash
python verify.py signal.wav
# unit = 0.145s
# decoded: Я ТЕБЯ ЛЮБЛЮ
```

**3. 自己听**

`signal.wav` 是 660 Hz 的蜂鸣，单位时长约 0.145 秒。短的是一点，长的是三倍——划。字与字之间空三个单位，词与词之间空七个单位。用耳朵也能数出来。

## 文件

| 文件 | 作用 |
|---|---|
| `morse.py` | 西里尔摩斯编解码表 + 命令行 |
| `verify.py` | 从 WAV 里把电码听回来，不读原文 |
| `make_signal.py` | 生成 WAV 和视频（文字是唯一输入） |
| `signal.wav` | 音频：7 秒静默，16.7 秒电码，9 秒静默 |
| `asya-signal.mp4` | 32 秒视频：黑底，符号逐字浮现 |

整段都从 `make_signal.py` 里的一个字符串生成。改掉那个字符串，音频和视频会一起变成另一句话。
